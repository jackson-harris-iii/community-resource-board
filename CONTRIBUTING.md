# Contributing

Keep participant access open in demo mode and moderation private. Use additive database migrations. Do not rename seeded idea IDs after votes exist. Tests must use a local database, never the public demo. Include tests for validation, authorization, public-response privacy and retries when changing those paths. Keep source dates and status in resource records. Submit a PR with behavior, risks and test commands; do not commit credentials, user records, recordings or third-party logos.
